# Ekran Görüntüleri

Ana `README.md` bu klasördeki görselleri gösterir. Aşağıdaki adlarla PNG ekleyin;
dosyaları koyduğunuzda README'de otomatik görünürler.

| Dosya adı | İçerik | Önerilen sayfa |
|-----------|--------|----------------|
| `dashboard.png` | Genel panel / kontrol ekranı | `/dashboard` |
| `files.png` | Dosya yöneticisi (çöp kutusu görünür) | `/files` |
| `domains.png` | Domain yönetimi listesi | `/domains` |
| `services.png` | Servis durumu (10 servis) | `/services` |

## ⚠️ Önemli: Temiz görsel kullanın

Bu repo **public** ve **kişiye özel veri içermemelidir**. Ekran görüntüsü alırken:

- **Gerçek alan adlarınızı** (kendi müşteri domainleriniz) gösteren ekranları **kullanmayın**.
- Tercihen **taze bir kurulumda** veya **demo verisiyle** (örn. `example.com`,
  `demo.test`) ekran görüntüsü alın.
- IP adresi, e-posta, kullanıcı adı gibi bilgileri görselde bırakmayın
  (gerekiyorsa bulanıklaştırın/karartın).

## Öneriler

- Genişlik ~1440px, koyu tema, tarayıcı çubuğu olmadan (sadece panel içeriği).
- PNG formatı, dosya başına ~300–600 KB (gerekirse sıkıştırın).
- Tutarlı olsun: hepsi aynı tema/çözünürlük.
